# Practical 3 — ASP.NET Core MVC

Two MVC projects based on Practical 3 of the .NET Technology journal.

- **pract3_1_97** — Stock quote (Nike, price 3500)
- **pract3_2_97** — Library book details (five sample books)

## Requirements
- Visual Studio 2026 with the ASP.NET and web development workload
- .NET 8 SDK

## Run
Open `Practical3_MVC.sln` in Visual Studio. Set either `pract3_1_97` or `pract3_2_97` as the startup project, then press Ctrl+F5.

Alternatively, run `dotnet run` from either project directory.
